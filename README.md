# Обработка изображений

Домашние задания по курсу «Обработка изображений», ИТММ ННГУ, 3 курс, осенний семестр 2026.

## Структура

- `task1/` — точечные операции: гистограмма, гамма-коррекция, эквализация, статистическая цветокоррекция, пороговая фильтрация

## Как запустить

```bash
uv sync
uv run jupyter lab
```

Зависимости зафиксированы в `pyproject.toml` и `uv.lock`.
